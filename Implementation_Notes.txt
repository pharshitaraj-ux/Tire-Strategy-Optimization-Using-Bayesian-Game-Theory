6.Feature Engineering
#------------------------------
These engineered features directly support your Bayesian game:
Players: F1 teams/drivers.
Types (private information): WeatherState (Dry/Wet).
Strategies: Strategy (e.g., SOFT_Short, HARD_Long).
Payoffs: PayoffScore, which combines lap performance and tyre longevity.
Environmental factors: TemperatureLevel and WeatherProbability.
Race decisions: PitStop and StintLength.
This provides the bridge between EDA and the Bayesian Game Theory model. 
After this, the next implementation step is to formulate the Bayesian game itself:
 define the players, strategies, types, payoff matrix, and compute the optimal strategy.

### New Features Created
| Feature            | Purpose                                                            |
| ------------------ | ------------------------------------------------------------------ |
| WeatherState       | Represents the weather state (Dry/Wet) for the Bayesian game type. |
| TemperatureLevel   | Categorises track temperature into Low/Medium/High.                |
| TyreWear           | Categorises tyre degradation into Low/Medium/High.                 |
| PitStop            | Indicates whether a pit stop occurred on the lap.                  |
| StintLength        | Categorises tyre stint as Short/Medium/Long.                       |
| PaceCategory       | Categorises lap pace as Fast/Normal/Slow.                          |
| CompoundCode       | Numerical encoding of tyre compounds.                              |
| Strategy           | Combined strategy label (e.g., `SOFT_Short`).                      |
| WeatherProbability | Prior probability of each weather state.                           |
| PayoffScore        | Performance score combining lap time and tyre wear.                |

These features are exactly the kind of inputs a Bayesian game model needs.

#------------------------------------------
Bayesian Nash Equilibrium
#------------------------------------------
This implementation computes the expected payoff of each strategy 
using the observed weather probabilities. Under the assumption that each 
team chooses the strategy that maximises its expected payoff given the uncertainty in weather, the recommended
strategy for each team represents the Bayesian equilibrium outcome in your simplified model.
For a project, this is a reasonable and defensible formulation. 
In a more advanced research setting, one could extend it to model strategic 
interactions where each team's payoff depends not only on its own strategy but also on the strategies
chosen by the other teams.

# Overall Interpretation of Bayesian Game Theory Results
The Bayesian Game Theory model successfully integrates historical Formula 1 race data with uncertain weather conditions to recommend optimal tyre strategies 
for competing teams. Unlike deterministic decision-making, the model incorporates prior probabilities of dry and wet 
weather when computing expected utilities. The resulting Bayesian Nash Equilibrium identifies the strategy that maximises
each team's expected payoff under uncertainty. The evaluation demonstrates that while all teams benefit from data-driven 
strategy selection, the optimal tyre choice differs according to each team's historical performance characteristics. 
These findings illustrate the practical applicability of Bayesian Game Theory for strategic decision-making in Formula 1,
where uncertainty plays a crucial role in race outcomes.
